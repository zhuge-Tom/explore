# Explore — AI 结构化思维与知识探索工具

> 哪里不懂点哪里。告别线性聊天框,让知识长成一棵树 🌲

## 一句话定位

Explore 是一款**多层级知识问答 Agent**:用户与 AI 的每一次追问不再淹没在聊天记录里,而是以「卡片」形式在无限画布上展开,形成一棵可视化的知识树;经过 AI 认可的个人理解会沉淀进 3D「思维宇宙」,成为专属于用户的知识锚点。

## 解决的核心问题

传统聊天框在深度学习场景下的三大痛点:

1. **上下文迷失** — 追问三轮后,用户和 AI 都忘了最初在聊什么;
2. **术语雪崩** — 一个回答抛出 10 个新术语,追问其中一个,又冒出更多,没有结构化的消化路径;
3. **知识不沉淀** — 聊完即忘,没有任何机制把「聊过的」变成「学会的」。

## 核心功能

| 功能 | 说明 |
|---|---|
| 层级对话 | 点击术语 → 新卡片丝滑展开,主线始终可见 |
| 三种卡片 | ↗️ 子卡片(深挖)/ ➡️ 关联卡片(横向对比)/ ⬇️ 分支卡片(继承上下文另起炉灶) |
| 文献导入 | 导入 PDF/论文,在原文上「哪里不懂点哪里」,回答带引用定位 |
| 思维宇宙 | 用自己的话总结 → AI 评审通过 → 存入 3D 知识网络,未来 AI 用你的知识锚点教你新概念 |

## 技术栈速览

- **前端**: Next.js (React + TypeScript) + React Flow(卡片画布)+ Three.js / react-force-graph-3d(思维宇宙)
- **后端**: Next.js API Routes / Node.js + `@anthropic-ai/sdk`
- **模型**: Claude Opus 5(`claude-opus-5`,主力)+ 自适应思考 + 流式输出
- **数据库**: PostgreSQL(卡片树)+ pgvector(思维宇宙向量)
- **嵌入**: Voyage AI(Anthropic 官方推荐的 embedding 服务)
